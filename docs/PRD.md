# SparkWhisper (烟花祝福生成器) - 产品需求文档 (PRD)

## 1. 项目简介
SparkWhisper 是一个纯静态的互动祝福网页应用。用户可以自定义祝福语和图片，生成一个包含所有数据的专属链接发送给好友。好友打开链接后，通过有趣的互动完成跨年仪式（2025 -> 2026），随后欣赏逼真的烟花秀并查收祝福。

## 2. 用户角色
- **发送者 (Creator)**: 配置祝福内容，生成链接。
- **接收者 (Viewer)**: 访问链接，体验互动与烟花秀。

## 3. 功能需求

### 3.1 发送者视图 (配置页)
**UI 风格**: 可爱、简约、新颖。

1.  **祝福语设置**:
    *   允许用户输入 0-5 条文本祝福语。
    *   每条祝福语有字数限制（建议 20 字以内），防止遮挡烟花。
2.  **图片上传**:
    *   允许用户上传 0-2 张图片。
    *   *技术限制*: 由于是纯静态无后端且通过 URL 传参，图片建议限制大小（如自动压缩或仅支持外部 URL，或者在技术实现上做 Base64 极度压缩）。
3.  **顺序调整**:
    *   提供可视化列表。
    *   支持拖拽排序（决定播放时文字/图片出现的先后顺序）。
4.  **预览与发布**:
    *   **预览按钮**: 在当前页弹窗演示效果。
    *   **发布按钮**: 点击后生成专属 URL。
    *   **URL 生成逻辑**: 将所有配置数据压缩编码拼接到 URL Hash 或 Search Params 中。

### 3.2 接收者视图 (播放页)
**入口**: 访问带有参数的 URL。

1.  **互动开场 (2025 -> 2026)**:
    *   **场景**: 屏幕显示 "2025"。
    *   **互动**: 用户需进行特定操作（如：滑动火柴点燃引信、擦除屏幕上的旧年份灰尘、用力拉动拉炮绳索等）来告别 2025。
    *   **反馈**: 完成互动后，2025 炸裂或消散，2026 闪亮登场，随即触发烟花秀。
2.  **烟花秀 (Core Experience)**:
    *   **视觉**: 极度逼真的 Canvas 烟花效果（粒子、重力、拖尾、光效）。
    *   **听觉**: 配合烟花绽放的爆炸声、升空声，以及温馨的背景音乐 (BGM)。
3.  **内容播放**:
    *   在烟花绽放的过程中，按照发送者设置的顺序，依次在屏幕合适位置（如烟花中心或特定的展示框）浮现祝福语和图片。
    *   播放完毕后，进入自由烟花模式（用户点击屏幕可燃放烟花）。

## 4. 非功能需求
- **性能**: 移动端首屏加载速度 < 2s，Canvas 动画在主流手机上保持 60fps。
- **兼容性**: 适配 iOS/Android 微信内置浏览器及主流 Mobile/PC 浏览器。
- **分享**: 考虑到 URL 较长，UI 上应提供“复制链接”功能，并提示用户链接包含所有数据。

## 5. UI/UX 参考
- **色调**: 深邃夜空蓝（背景）+ 暖金/霓虹色（烟花）+ 柔和粉/白（UI 控件）。
- **字体**: 圆润可爱的字体（如 Rounded Mplus 或类似手写体）。
